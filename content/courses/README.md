# Engineering lesson drafts

These are original, source-attributed lesson drafts for integration review. They are not published lessons or complete courses. Each subject file contains three short lessons. No published retry-safe-credit content or hash is changed.

The `Source` links were checked against the named publisher on 2026-10-18. The examples and concept checks are original to TrajectoryOs. The `Open question` field records a claim or product decision to settle before publication. Existing team Google Docs and ChaiCode notes were not available for review, so this material does not claim to use them.
